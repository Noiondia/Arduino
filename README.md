<b>¿Qué es Arduino?</b>
<br>Arduino es una plataforma de hardware y software de codigo abierto que permite crear objetos electronicos interactivos.

<b>¿Cuáles son sus características más importantes?</b>
<br>Aunque arduino tiene ,uchas características una de ellas seria su accesibilidad; hardware y software de codigo abierto y la facilidad de uso gracias a su IDE basado en C++

<b>¿Cuál es el origen de Arduino?</b>
<br>Se originó en 2005, en el instituto de diseño de interacción de IVREA, en italia, como una herramienta de aprendizaje de bajo coste, para que los estudiantes y quien quisiera aprender, pudiera hacerlo de forma sencilla.

<b>¿Para qué sirve un Arduino?</b>
<br>Arduino sirve como una plataforma electrónica de código abierto que permite crear proyectos interactivos.

<b>¿Qué lenguaje utiliza?</b>
<br>El lenguaje que utiliza seria C y C++

<b>¿Qué es el Arduino IDE?</b>
<br>Arduino IDE es el programa oficial que se utiliza para escribir, editar y cargar el código en las placas Arduino.


<H1>Actividad Blink+Semáforo</H1>

<b>¿Qué son el void setup and void loop?</b>
<br>Void setup es una función que se ejecuta una sola vez al iniciar el programa.
<br>Void loop es la función que Arduino ejecuta una y otra vez en un ciclo infinito.

<b>¿Qué quiere decir la línea: #define LED_BUITIN 2?</b>
<br>Sirve para crear un nombre simbólico que será reemplazado por un valor antes de compilar el programa.

<b>Qué quiere decir la línea delay(1000);?</b>
<br> Detiene la ejecución del programa durante el tiempo indicado en milisegundos
